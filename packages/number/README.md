# @aleclloydprobert/number

Aggregate package for the `number` module tree in [raindrops-on-roses](https://www.npmjs.com/package/raindrops-on-roses).

## Install

```sh
npm install @aleclloydprobert/number
```

## Usage

```ts
import { /* utilities */ } from "@aleclloydprobert/number";
```

## Included packages

- `@aleclloydprobert/number-clamp`
- `@aleclloydprobert/number-nice-number`
- `@aleclloydprobert/number-numbers-from-seed`

## Complete library

You can also install the complete library:

```sh
npm install raindrops-on-roses
```
